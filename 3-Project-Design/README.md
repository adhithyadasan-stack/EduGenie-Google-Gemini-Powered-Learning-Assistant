Project Design Phase
App Flow:
Student opens EduGenie
Student types a topic or question
Student selects Explain, Summarize, or Quiz
App sends the request to the Gemini API
Response is displayed on screen
UI Design:
Clean, simple layout with a single input box
Three clear action buttons: Explain, Summarize, Quiz
Results shown directly below the input box
Responsive design that works on both phone and computer screens
Design Tools Used:
Google AI Studio (Build mode) for generating the UI and layout
